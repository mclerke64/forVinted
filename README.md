## 🎯 Project Overview
The goal of this assignment was to create a structured movie trailer dashboard. 
* **The Challenge:** Perfectly match the requested design and layout expectations.
* **The Solution:** Built a two-column responsive layout using a clean sidebar navigation (`<aside>`) and a structured main content area (`<main>`) housing responsive embedded YouTube video players.

## 🛠️ Tech Stack
* **HTML5:** Semantic tags (`<aside>`, `<main>`, `<section>`, `<ul>`) for great accessibility and structure.
* **CSS3:** Custom styling, layouts, and typography.
